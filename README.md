## 🧩 Frameworks & libraries

- ⭐ [Stars Components](https://stars-components.js.org). HTTP-first TypeScript framework and toolkit for building Discord applications, plus a set of plugins on top.
- 🎨 [newt-ui](https://newtui.dev). Discord-styled component library for React, Vue and plain HTML/CSS, built on one shared design token system.
- 💉 [unplugin-version-injector](https://github.com/RedStar071/unplugin-version-injector). Injects your package version or build date into built files. Works with Vite, Rollup, Rolldown, esbuild, Webpack, Rspack and Farm.
